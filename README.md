# Decatur Mechanic Landing

Build a production-ready, single-page React landing page for **Decatur Mechanic**, optimized for high-intent Google Search Ads traffic and mobile phone-call conversions.

**An UI reference image will be attached directly in Lovable with this prompt. Use it as the primary visual reference.** Follow it closely for composition, proportions, color direction, typography personality, section density, card geometry, borders, buttons, image placement, and desktop/mobile rhythm. Do not copy its business name, logo, text, images, reviews, phone number, or other factual content.

## Scope

Build exactly one homepage with no additional routes, pages, CMS, authentication, dashboard, booking system, blog, e-commerce, or thank-you page. Navigation must use anchor links. The page must contain exactly seven major sections, in the order below. The utility bar, header, sticky mobile actions, form panel, and footer do not count as major sections.

Primary conversion: qualified phone calls.

Secondary conversions:

- Text enquiry

- Short estimate request

- Directions interaction

## Global Visual Direction

Use the reference image’s industrial editorial style:

- Dark navy or near-black surfaces

- White content sections

- Safety-orange accents

- Condensed, bold display headings

- Compact section spacing

- Thin borders

- Practical rectangular cards

- Square or lightly rounded buttons

- Strong image crops

- High contrast

Avoid SaaS styling, excessive rounded cards, large shadows, racing graphics, flames, neon, carbon-fiber textures, fake metal, heavy gradients, background video, sliders, parallax, and complex 3D effects.

Mobile is the primary layout. Design intentionally for 375px, 390px, and 430px. Use 44–48px touch targets, short paragraphs, no horizontal overflow, no tiny text, no intrusive popups, and correct safe-area spacing.

Desktop should use a controlled maximum width, strong horizontal alignment, useful image sizes, compact multi-column layouts, and no excessive empty space.
